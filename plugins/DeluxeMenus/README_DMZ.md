# DeluxeMenus — DMZ Adaptive Difficulty

Menus opened by the Forge mod when a player runs `/difficulty`:

| Menu key | File | Purpose |
|---|---|---|
| `dmz_difficulty` | `gui_menus/dmz_difficulty.yml` | Main controls |
| `dmz_difficulty_rewards` | `gui_menus/dmz_difficulty_rewards.yml` | Reward multipliers |
| `dmz_difficulty_tiers` | `gui_menus/dmz_difficulty_tiers.yml` | Enemy tiers |
| `dmz_difficulty_stats` | `gui_menus/dmz_difficulty_stats.yml` | Statistics |

Requires **PlaceholderAPI** and **`dmz_adaptive_difficulty_gui-*.jar`** for `%dmzdiff_*%` placeholders.

Reload after edits: `/dm reload`
