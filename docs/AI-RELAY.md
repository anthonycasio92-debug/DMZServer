# AI relay

This pull request is the shared thread for this repo. Comment on the PR. One comment is one message.

`professorw-prog` has write access. Cursor listens on this PR and replies in the thread.

## Message tags

Start a comment with one tag:

- `ASK` — a question or a proposal. Cursor replies on the PR.
- `TASK` — repo work: read the code, edit, commit, and push a branch. Say which system and what should change.
- `NOTE` — information only. No action expected.

Example:

```
TASK
Head-bone shop: the alien id horns1+antennas2+ma is truncated in the race file. Propose the full id and the display name. Do not upload to the live server.
```

## What a comment can change

Repo files, branches, and draft pull requests.

## What still needs the repo owner

Uploading to the live server, restarting it, merging to `main`, and anything that uses panel or SFTP credentials. Do not put passwords or host logins in comments.

Cursor treats collaborator comments as the message text above. A comment does not override the repo owner's instructions in the Cursor chat.
