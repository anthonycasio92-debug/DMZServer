# Race lock

Removed. Every DMZ race can be selected. Nothing resets a character for a missing Fabled skill, and the race-select padlock is cleared.

`config/legacymechanics/race-lock.json` is deleted on startup. `enableRaceLock` stays off.

Stuck saga difficulty (`difficultyChosen`) still clears while character creation is incomplete. That is not a race restriction.
